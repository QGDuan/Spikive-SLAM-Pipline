## 1. Basic facts

This module has no standalone Dockerfile and no standalone build script. Build methods per block:

| Block | Build | Artifact |
|---|---|---|
| `ins_preprocess.cpp` | target `lsdc_ins_preprocess` at `Spikive-SLAM/CMakeLists.txt:109-111` | `devel/lib/lsdc_slam/lsdc_ins_preprocess` |
| `rs_to_velodyne.cpp` | target `rs_velodyne` at `Spikive-SLAM/CMakeLists.txt:100-102` | `devel/lib/lsdc_slam/rs_velodyne` |
| `preprocess.cpp` / `pcl_preprocess.hpp` | compiled into the `lsdc_mapping` target (`CMakeLists.txt:104`; the source list includes `src/LIO/preprocess.cpp`) | no standalone artifact |

Image, environment variables and catkin workspace assembly are the same as for the SLAM module; see `../slam/docker-build.md`. This page only lists the differences relevant to this module.

## 2. Dependencies of this module

| Dependency | Source |
|---|---|
| GeographicLib | `lsdc_ins_preprocess` links `GeographicLib_LIBRARIES` (`CMakeLists.txt:111`) |
| PCL | `rs_velodyne` links `${PCL_LIBRARIES}` (`CMakeLists.txt:102`) |
| OpenCV | `rs_velodyne` links `${OpenCV_LIBRARIES}` (`CMakeLists.txt:102`; the file never runs `find_package(OpenCV)`, so the variable is empty in the default environment [TBC]) |
| `livox_ros_driver` message headers | `ins_preprocess.cpp:6` includes `<livox_ros_driver/CustomMsg.h>`; `preprocess.h:3` likewise. The workspace must contain the `livox_ros_driver` package |

## 3. Build command

Shares the catkin build command of the SLAM module (taken from `Spikive-PGO/scripts/dev.sh`):

```bash
catkin_make -j4 -DCMAKE_BUILD_TYPE=Release -DCATKIN_WHITELIST_PACKAGES= \
  -DCMAKE_PREFIX_PATH=/opt/spikive\;/opt/ros/noetic \
  -DCeres_DIR=/opt/spikive/lib/cmake/Ceres \
  -DGTSAM_DIR=/opt/spikive/lib/cmake/GTSAM
```

To build only the targets of this module:

```bash
catkin_make --only-pkg-with-deps lsdc_slam
```

(`--only-pkg-with-deps` is a standard catkin_make option; verify the exact usage on site [TBC].)

## 5. Common errors and handling

| Symptom (basis) | Handling |
|---|---|
| `ins_preprocess.cpp` fails to compile: `<livox_ros_driver/CustomMsg.h>` not found (`ins_preprocess.cpp:6`) | Put the `livox_ros_driver` sources into `/ws/src` and rebuild; the header is generated by its `generate_messages` |
| `lsdc_ins_preprocess` link failure: GeographicLib not found | Install `libgeographic-dev` (present in the image) |
| S10U point-cloud related compile errors | The S10U point structure `lx_ros::Point` is defined at `preprocess.h:83-102` and must match the driver message fields; adjust per that structure on mismatch |
